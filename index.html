Protección de datos

Esta edición funciona sin servidor ni cuenta: guarda todo únicamente en el navegador y dispositivo que uses. Netlify aloja la web, pero no sincroniza tus datos entre celulares/computadoras. Exporta respaldos frecuentemente; borrar datos del navegador puede eliminar tus registros. Las imágenes se comprimen para ahorrar espacio.
